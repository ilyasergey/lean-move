**File:** `LeanMove/Checker/TypeChecking.lean`
**Description:** Change the return rule approach from checking "mutable inputs have non-trivial outbound edges" to checking "no local variables are borrowed". This is the preferred formulation because:

**Solution:** Added `no_locals_borrowed` helper and updated `return` rule to use it.

**File:** `LeanMove/Checker/TypeChecking.lean`
**Description:** Implement `typecheck_fun` relation that type checks an entire function definition:
- Initialize `TypeEnv` from function parameters (add params to `varEnv` as valid mutable variables)
- Initialize `TypeEnv` from local variable declarations (add locals to `varEnv` as invalid variables)

**Solution:** Added helper functions and `typecheck_fun` inductive relation.
